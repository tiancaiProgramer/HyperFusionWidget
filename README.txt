HyperFusionWidget 0.0.6（融合设备卡片）

完整说明请查看仓库 README.md。
本版本提供 HyperOS 融合设备中心的负一屏卡片与标准 AppWidget。
海尔等其他平台仍在调研阶段，未包含相关设备控制实现。

构建：python3 tools/fetch_xposed_api.py，然后按 README.md 设置 JDK 与 Android SDK 并运行 python3 build.py。
安装包：GitHub Releases 中的 HyperFusionWidget-0.0.6.apk。
启用说明、测试版本与 MiLink 兼容模式集中在首页「关于」。
兼容模式默认开启，可在「关于」中手动关闭；已有手动选择会保留。
