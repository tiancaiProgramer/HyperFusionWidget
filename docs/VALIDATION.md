# 验证范围

公开版本为 0.0.1。功能实现沿用内部预览版，公开整理包括版本元数据、构建脚本和文档更新。内部预览版的运行验证不能替代其他机型或系统版本的兼容验证。

## 构建检查

- Java 编译与 Android 资源打包。
- 11 项主机 JVM 检查：签名、精确 UID、共享 UID 拒绝、其他用户拒绝、系统和 Root UID 拒绝、状态位解析及直接执行场景识别。
- APK 签名、对齐与现代模块入口检查。
- Maven Central 编译依赖固定 SHA-256 校验。

## 已有实机验证

以下验证基于 README 所列 MIX Fold 3 / HyperOS / MiLink / 智能助理组合，在内部预览版完成：

- 模块安装、两个目标进程加载、真实设备列表读取。
- 原生负一屏 AppWidget 绑定、卡片展示、刷新与重复添加保护。
- 从负一屏点击手机设备，弹出包含电量与控制入口的原生面板。
- “更多”跳转正常，用户确认去掉中转页面后闪烁问题消失。
- App 内添加请求完成重复检查后返回；普通系统选择器没有附加按钮。

## 未完整验证

- 当前 App 内自动添加流程在删除已有卡片后重新首次放置，尚未重测。
- 所有设备种类的面板及具体控制动作。
- 桌面放置、内屏布局与折叠切换。
- 长期后台调度、锁屏恢复和网络变化后的恢复。
- 其他 HyperOS / MiLink / 智能助理版本。
- 海尔等其他平台的接入。

0.0.1 发布时没有为了修改版本号再次安装到测试手机。
